# Replado für Unraid

Vorlage für Unraid Community Applications. Replado ist ein KI-Assistent für Kundenmails: Er liest das Postfach, ordnet jede Anfrage ein und schreibt einen Antwortentwurf mit Daten aus Shop und Warenwirtschaft. Ohne Lizenz läuft die Testversion, gesendet wird dann nichts.

- Website: https://replado.com
- Anleitung: https://replado.com/de/installation/
- Image: `ghcr.io/replado/replado` (amd64 und arm64)

Den Einrichtungscode für das erste Konto zeigt das Protokoll des Containers.
